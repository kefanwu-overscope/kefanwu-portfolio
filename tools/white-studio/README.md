# White studio derivatives — local review, 2026-10-11

The white covers and both full animation catalogs are generated by the current
Three.js r185 project inspector. The inspector loads the authoritative hashed
geometry/motion packages in `assets/studio-motion/index.json`; it applies the
existing photo-supported material and source surface shaders without changes.
The neutral environment, lights, source camera, motion, and scientific palettes
are retained. Historical Blender rendering tools reproduce older versions and
are not the entry point for this derivative.

The inspector receives `transparentBackground:false, backgroundColor:0xffffff`.
White participates in the physical transmission pass, so clear acrylic and
polymer refract the white studio. Native WebGL antialiasing supplies object edges.
The encoder composites onto an opaque white canvas; no dark-pixel selection,
image filtering, geometry edits or generative imagery is involved.

From the repository directory:

1. Run `python tools/white-studio/pack.py --snapshot` once to record all existing
   immutable frames, chunks, covers, source manifests/buffers and material/motion
   scripts (4,599 files). Do not replace this evidence after changing a source.
2. Run `node tools/white-studio/serve.mjs`. The server binds only to loopback port 4196
   and restricts local export writes to the dated evidence directory below.
3. Open `http://127.0.0.1:4196/__qa/export.html` in a visible browser tab. Click
   **Render white sample proof** to inspect seven representative projects at
   start/middle/end and 960-pixel covers. Review the white/clear Smelly structure,
   Vine polymer, carbon, metal, painted guitar and untouched scientific colors.
4. Click **Render all white covers and frames**. Keep the tab visible until all 16
   projects pass. `?only=key,key` is available for focused review but does not
   satisfy the complete pack contract. Re-run the full export before packing.
5. Run `python tools/white-studio/pack.py`, then
   `python tools/white-studio/verify.py`.

If Python is not on PATH, use the bundled runtime returned by
`load_workspace_dependencies`. Evidence/exports are stored under
`../.codex/white-studio-20261011/`. The server and proof buttons are local QA
tools; production pages do not import them.

New outputs use `assets/exploded/white-20261011/` and
`assets/editorial/white-20261011/`. The two new catalog files are
`assets/exploded/manifest-white-20261011.json` and
`assets/exploded/manifest-detail-white-20261011.json`; the cover catalog is
`assets/editorial/white-20261011/animation-covers.json`, and annotation data is
`assets/exploded/white-20261011/anchors.json`. Existing catalogs and dated asset
directories remain byte-identical; integration switches the consuming URLs.

The export retains 2,032 positions per catalog, 640×427 SD and 1280×854 HD frames,
three cover widths 480/960/1800, progress-zero covers, 2,032 component anchors and
72 phase occupancy masks. Chunks contain the original encoded WebP bytes:
at most 4 bootstrap frames, then 16 frames, and never more than 256 KiB.
The validator checks every file hash, dimension and white corner, every chunk
slice, matching source-pose metadata, unchanged annotations/scientific legend,
compiled source shaders, and unchanged preservation snapshot. The native render
and canvas are exactly #fff. Efficient lossy WebP encoding may shift compressed
corner channels by at most 3 levels (252–255); measured corner counts are recorded
in the pack/verification reports. No model or background pixels are filtered.

These files are for local review. This workflow does not commit, push or publish.

## Verified local output

The complete export took 198.6 seconds, including initial background-browser
throttling. Bringing the render tab to the foreground restored normal cadence.
The final validator passed 4,064 frames, 385 chunks, 48 cover variants, 2,032
identical component anchors and 72 identical occupancy masks. All 4,599 preserved
source/catalog/old-asset hashes match. SD image bytes are 20,004,318 and HD image
bytes are 48,905,572, a combined increase of about 0.166% over the prior catalogs.
All animation corners are exact 255 white. Five 1800-pixel covers have one corner
channel at 253; all other cover corners are exact white. Evidence:
`../.codex/white-studio-20261011/asset-verification.json` from the repository root.
